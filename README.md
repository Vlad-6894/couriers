# 📦 Couriers

Бэкенд-платформа на языке **Go**, разработанная для автоматизации логистических процессов, эффективного управления курьерскими службами и обработки заказов на доставку в режиме реального времени. 

Проект построен по принципам чистой архитектуры (**Clean Architecture**) и готов к высоким нагрузкам благодаря асинхронному обмену сообщениями и кэшированию.

---

## ⚙️ Функционал приложения

Сервис предоставляет комплексное API для автоматизации доставки и включает в себя следующие ключевые модули:

### 1. Управление курьерами (Courier Management)
* **Профили курьеров:** Полный цикл CRUD для управления учетными записями курьеров.
* **Статусы работы:** Динамическая смена состояний курьера в реальном времени (например: *Свободен*, *В пути*, *На перерыве*, *Оффлайн*).
* **Типы транспорта:** Поддержка различных типов передвижения (пеший, велосипед, самокат, автомобиль) для оптимизации логистики.

### 2. Обработка заказов и диспетчеризация (Order Processing)
* **Жизненный цикл заказа:** Создание, отслеживание этапов сборки, передачи курьеру и финальной доставки клиенту.
* **Умное распределение:** Логика автоматического подбора оптимального курьера на основе его текущего местоположения, статуса и типа транспорта.

### 3. Обработка событий в реальном времени (Event-Driven Architecture)
* **Асинхронные уведомления:** Публикация событий об изменении статусов заказов или координат курьеров для смежных микросервисов.
* **Очереди задач:** Надежная обработка транзакционных событий доставки без блокировки основного API.

### 4. Кэширование и гео-данные
* **Мгновенный доступ:** Кэширование часто запрашиваемых данных курьеров и активных заказов для снижения нагрузки на основную БД.
* **Быстрое обновление:** Инвалидация кэша при обновлении статусов доставки.

## 🛠️ Стек технологий

Проект использует современный и производительный стек для обеспечения отказоустойчивости:

* **Core:** `Go (Golang)` — высокая производительность и эффективная конкурентность.
* **Основная БД:** `PostgreSQL` — надежное реляционное хранилище для профилей, заказов и истории доставок.
* **Кэш / Спец. хранилище:** `Redis` — кэширование горячих данных и быстрых статусов курьеров.
* **Брокер сообщений:** `Apache Kafka` — асинхронная шина событий для обмена сообщениями между компонентами системы.
* **Контейнеризация:** `Docker` & `Docker Compose` — изолированное развертывание сервиса и всей инфраструктуры одной командой.
* **Автоматизация:** `Makefile` — скриптование рутинных команд разработки.
